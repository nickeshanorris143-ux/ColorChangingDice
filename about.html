About My Project

Why I Created This Website

This project is a simple dice game created with HTML, CSS, and JavaScript.

What I Learned

HTML creates the structure of the website. CSS controls the appearance and colors. JavaScript makes the dice interactive by generating random numbers and changing colors.

How It Works

When the player clicks the Roll Dice button, JavaScript generates a number from 1 to 6 and selects a new color for the die.
